# 01: 무창 기본 검증선 분리

**What to build:** 개발자와 에이전트가 일반 검증을 실행할 때 Electron 앱이나 창을 만들지 않고
린트, 타입 검사와 모든 단위 테스트만 빠르게 확인할 수 있는 기본 검증선.

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] 데스크톱 기본 테스트는 소스 아래의 단위 테스트만 수집하고 Electron 제품 흐름을 수집하지 않는다.
- [ ] 루트 기본 테스트는 코어와 데스크톱의 모든 단위 테스트를 실행한다.
- [ ] `pnpm verify`는 린트, 타입 검사와 모든 단위 테스트를 실행한다.
- [ ] `pnpm test`와 `pnpm verify`를 실행해도 Electron 프로세스나 네이티브 창이 만들어지지 않는다.
- [ ] 기존 Electron 제품 흐름은 명시적 제품 테스트로 계속 실행할 수 있고 시나리오가 삭제되지 않는다.
- [ ] 테스트 수집 목록으로 기본 검증과 제품 흐름의 경계가 고정되어 이후 파일 추가로 다시 섞이지 않는다.
- [ ] 변경 뒤 기본 테스트, `pnpm verify`와 정적 검사가 통과한다.
