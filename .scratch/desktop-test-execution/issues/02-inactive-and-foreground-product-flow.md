# 02: 비활성·전면 Electron 제품 흐름

**What to build:** 같은 전체 Electron 제품 흐름을 평소에는 사용자의 포커스를 빼앗지 않는
비활성 창으로 실행하고, 명시적인 수용 검증에서는 프로덕션과 같은 전면 창으로 실행할 수 있는
두 제품 검증선.

**Blocked by:** 01/무창 기본 검증선 분리.

**Status:** ready-for-agent

- [x] `pnpm test:product`는 데스크톱 앱을 빌드한 뒤 기존 전체 제품 흐름을 비활성 모드로 실행한다.
- [x] `pnpm test:product:foreground`는 같은 빌드와 같은 전체 시나리오를 프로덕션 표시·포커스 경로로 실행한다.
- [x] 비활성·전면 모드는 시나리오를 복제하지 않고 하나의 제품 흐름 seam을 공유한다.
- [x] 비활성 모드의 팝오버는 실제로 표시되지만 최초 표시 뒤 네이티브 포커스를 갖지 않는다.
- [x] 비활성 모드에서는 대화상자 종료와 파일 관리자 흐름을 포함한 모든 네이티브 포커스 복귀 요청이 억제된다.
- [x] 제품 흐름이 최초 표시와 대화상자 종료 뒤 실제 창의 비포커스 상태를 자동으로 확인한다.
- [x] 비활성 표시 계약을 만들 수 없으면 전면 표시, 화면 밖 이동 또는 완전 숨김으로 폴백하지 않고 명확히 실패한다.
- [x] 일반 앱 실행과 전면 제품 흐름의 기존 `show()`·`focus()` 동작은 바뀌지 않는다.
- [x] `pnpm verify:product`는 기본 검증이 성공한 뒤 비활성 제품 흐름을 순차 실행하며 둘을 병렬화하지 않는다.
- [x] 성공·실패 모두에서 Electron과 보조 프로세스 및 임시 사용자 데이터가 정리된다.
- [x] macOS 비활성 전체 제품 흐름과 전면 전체 제품 흐름이 마지막 변경 이후 통과한다.
- [x] 자동 제품 흐름 결과를 실제 운영체제 포커스·블러·트레이 동작의 증거로 표현하지 않는다.
