## Comments

- `HistoryTab`은 리스트·달력 전환을 유지하고, 코어의 `groupHistory`와 `expiryLosses` 결과를
  그대로 사용해 예정·사용·소멸 상태를 파생한다. 공용 `CalendarGrid`의 날짜 계산과 셀 장식에
  접근 가능한 날짜 상태 문구를 더했으며, 상태 범례도 함께 노출한다.
- 선택한 날짜의 기록은 날짜·단위·메모와 예정·사용 문맥을 같은 상세 영역에서 보여준다. 단위
  변경과 삭제는 기존 커밋 통로를 사용하고, 성공한 상태 푸시로 잔여·상세·달력 장식이 갱신된다.
- `product-flow.test.ts`에 월 이동, 예정·사용 상태 문구, 소멸 수량 설명, 날짜 상세, 키보드
  단위 변경·삭제와 보기 전환을 실제 Electron 흐름으로 추가했다. `Tab` 포커스와 포커스 테두리,
  `aria-pressed` 선택 상태도 확인한다.
- `pnpm typecheck`, `pnpm test`, `pnpm lint`와 `pnpm --filter @yeoncha/desktop test:product`
  확인 결과 전체 테스트 24건과 Electron 제품 흐름 17건이 통과했다. 제품 흐름은 macOS에서
  실행했으며 Windows 실제 팝오버 렌더링·트레이 동작의 증거로 간주하지 않는다.
