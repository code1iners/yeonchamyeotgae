# 07: 원장형 휴가 이력 달력과 날짜 조작

**What to build:** 휴가 이력의 달력에서 예정·사용·소멸을 날짜로 파악하고, 선택한 날짜의 휴가
기록을 현재 맥락에서 변경하거나 삭제하는 흐름.

**Blocked by:** 06/원장형 휴가 이력 리스트와 즉시 변경.

**Status:** ready-for-agent

- [ ] 리스트와 달력 보기를 같은 이력 화면에서 전환할 수 있다.
- [ ] 예정과 사용은 색뿐 아니라 접근 가능한 문구나 상태 정보로 구분된다.
- [ ] 소멸일은 날짜에 표시되고 그날을 선택하면 무엇이 얼마나 소멸했는지 설명한다.
- [ ] 날짜를 선택하면 같은 화면 안에서 그날 휴가 기록의 날짜, 단위와 메모를 확인한다.
- [ ] 선택한 기록의 단위를 변경하거나 삭제하면 잔여와 달력 상태가 즉시 갱신된다.
- [ ] 사용과 예정은 조회일에서 파생되며 사용자가 수동 상태를 저장하는 UI가 없다.
- [ ] 등록 흐름과 같은 달력 계산·셀 의미를 재사용하고 날짜 규칙을 별도로 구현하지 않는다.
- [ ] 키보드로 월 이동, 날짜 선택, 단위 변경과 삭제를 수행할 수 있다.
- [ ] Electron 제품 흐름이 보기 전환, 날짜 상태, 소멸 설명과 기록 변경을 검증한다.
