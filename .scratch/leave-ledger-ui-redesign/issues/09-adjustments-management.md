# 09: 원장형 조정 관리

**What to build:** 이월·사규 추가분·포상 휴가를 계산이 만든 발생과 구분해 원장 행으로 보고,
조정을 추가·수정·삭제한 뒤 잔여 변화를 확인하는 흐름.

**Blocked by:** 08/원장형 입사일·기준방식 설정.

**Status:** ready-for-agent

- [ ] 조정이 발생일, 소멸일, 일수와 메모가 정렬된 원장 행으로 표시된다.
- [ ] 새 조정을 추가하고 기존 조정을 같은 맥락에서 수정하거나 삭제할 수 있다.
- [ ] 양수와 음수 조정을 모두 입력할 수 있고 일수는 0.25일 단위를 지킨다.
- [ ] 발생일과 소멸일의 유효성, 빈 값과 잘못된 일수를 저장 전에 설명한다.
- [ ] 소멸일 기본값은 기존 살아 있는 발생분 규칙을 유지하며 값을 지어내지 않는다.
- [ ] 계산이 만든 발생은 조정으로 덮어쓰지 않고 별도 근거로 남는다.
- [ ] 저장 중 중복 조작이 막히고 실패 시 열어 둔 입력 맥락이 유지된다.
- [ ] 추가·수정·삭제 후 잔여와 요약의 발생분 근거가 즉시 갱신된다.
- [ ] Electron 제품 흐름이 양수·음수 조정, 수정·삭제와 잔여 갱신을 검증한다.
- [ ] 기존 조정 유효성 단위 테스트가 회귀 없이 통과한다.
