## Comments

- `AdjustmentsSection`을 의미 있는 table/form으로 정리해 발생일·소멸일·일수·메모·행동을 고정 열에 배치하고, 추가·수정·삭제와 0.25 단위 양수·음수 입력을 같은 설정 맥락에서 처리했다. 계산된 월차·연차는 조정 표와 요약에서 별도 근거로 유지한다.
- 기존 `validateAdjustmentDraft`와 `latestLivingExpiry` 규칙을 유지하고 오류를 각 입력에 연결했다. `useCommit`에 동시 호출 잠금을 추가해 저장 중 중복 조작을 막으며, 실패 시 입력값과 열린 맥락을 보존한다.
- `apps/desktop/e2e/product-flow.test.ts`에 표 열 정렬, 기본값·잘못된 일수, 양수 추가·음수 수정·삭제, 계산 발생분 근거, 잔여 즉시 갱신과 저장 실패 재시도를 추가했다.
- 검증: `pnpm --filter @yeoncha/desktop test:product -- product-flow.test.ts` 22/22, `pnpm exec turbo run lint typecheck test --force` 6/6 작업 성공(코어 123개·데스크톱 32개 테스트).
- Electron 제품 흐름은 격리된 저장 데이터로 macOS에서 검증했으며, Windows 실제 동작 증거로 간주하지 않는다.
