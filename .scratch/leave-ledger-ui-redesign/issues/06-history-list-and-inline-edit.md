# 06: 원장형 휴가 이력 리스트와 즉시 변경

**What to build:** 예정과 사용을 원장형 행으로 빠르게 훑고, 현재 행에서 휴가 기록을 수정하거나
삭제한 뒤 잔여 변화를 바로 확인할 수 있는 휴가 이력 리스트.

**Blocked by:** 02/잔액 원장 디자인 계약과 팝오버 셸.

**Status:** resolved

- [x] 예정이 리스트 맨 위 별도 섹션에 있고 문구와 기호로 사용과 구분된다.
- [x] 사용은 연차 연도별로 접혀 있으며 현재 연차 연도만 처음 펼쳐진다.
- [x] 소멸된 발생분은 리스트 아래쪽에 배치되어 현재 기록을 방해하지 않는다.
- [x] 날짜, 단위, 메모와 상태가 고정 열에 정렬되고 행의 값이나 행동이 나타나도 열이 흔들리지 않는다.
- [x] 수정·삭제 행동은 포인터 hover와 키보드 포커스 모두에서 발견할 수 있다.
- [x] 수정은 현재 행에서 날짜와 단위를 바꾸며 하루 한 건 불변식을 지킨다.
- [x] 삭제와 수정 실패는 작업 중인 행과 맞는 위치에서 설명되고 입력 맥락을 유지한다.
- [x] 수정·삭제 성공 후 잔여와 휴가 이력이 즉시 갱신된다.
- [x] 긴 휴가 이력에서는 리스트만 스크롤하고 팝오버 머리와 탭은 유지된다.
- [x] Electron 제품 흐름이 예정 구분, 연차 연도 펼침, 인라인 수정·삭제와 잔여 갱신을 검증한다.

## Comments

- `HistoryTab`의 휴가 기록을 접근 가능한 `article` 단위로 묶고 날짜·단위·상태·메모·행동을 고정 grid 열에 배치했다. 사용/예정 문구를 모두 노출하고 행 hover와 키보드 포커스에서 수정·삭제 행동을 발견할 수 있게 유지했다.
- 인라인 수정은 날짜·단위 초안을 현재 행에서 저장하며 중복 날짜를 막는다. 삭제 실패는 해당 행 아래에 표시하고, 수정·삭제 성공은 기존 커밋 통로의 상태 push를 통해 잔여와 이력을 즉시 갱신한다.
- `product-flow.test.ts`에 예정 상단 분리, 현재 연차 연도 기본 펼침, 이전 연도 접힘, 소멸 하단 배치, hover/키보드 행동 발견, 인라인 수정·삭제, 실패 시 입력 맥락·행 위치, 잔여 갱신과 목록 전용 스크롤을 격리 Electron 흐름으로 추가했다.
- 확인 결과 `pnpm --filter @yeoncha/desktop test:product -- product-flow.test.ts`에서 16건, `pnpm --filter @yeoncha/desktop typecheck`, `pnpm --filter @yeoncha/desktop lint`가 통과했다. Windows 실제 제품 검증은 이 환경에서 수행하지 않았다.
