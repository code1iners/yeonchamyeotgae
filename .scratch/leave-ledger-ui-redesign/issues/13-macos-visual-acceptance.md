# 13: macOS 제품 수용 검증과 컴프 대조

**What to build:** 실제 macOS 메뉴 막대 앱에서 잔액 원장 재설계의 전체 사용자 흐름을 실행하고,
승인된 컴프와 정보 위계·정렬·주요 행동 위치를 대조해 발견한 차이를 같은 범위에서 해소한다.

**Blocked by:** 12/기존 시각 계약 제거와 공통 접근성 수축.

**Status:** ready-for-agent

- [ ] 실제 macOS Electron 앱에서 트레이 숫자와 팝오버 열기·닫기가 기존 계약대로 동작한다.
- [ ] 잔여 첫 화면, 빠른 등록, 확장 등록, 이력 수정·삭제, 설정·조정과 복구 흐름을 끝까지 수행한다.
- [ ] 최초 뷰포트의 잔여와 휴가 등록 위치, 380px 폭, 동적 높이와 내부 스크롤을 실제 기하로 확인한다.
- [ ] 잔여 첫 화면, 등록면과 이력 수정 상태의 결정론적 스크린샷을 승인된 컴프와 대조한다.
- [ ] 라이트·다크 테마와 시스템 글꼴에서 숫자·날짜 열, 대비와 포커스가 읽힌다.
- [ ] 컴프 대조에서 발견한 정보 위계, 정렬 또는 조작 발견성 차이를 이 티켓 안에서 수정한다.
- [ ] 제품 흐름에서 사용한 데이터가 실제 사용자 저장 파일과 분리되어 있다.
- [ ] 마지막 수정 이후 정적 검사, 전체 자동 테스트와 macOS Electron 제품 흐름이 다시 통과한다.
- [ ] macOS 결과를 Windows 검증의 증거로 표현하지 않는다.
