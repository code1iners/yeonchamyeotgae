## Comments

### 2026-09-02 — macOS 시각 수용 실행

- 실제 Electron 포그라운드 제품 흐름에서 잔여 첫 화면, 빠른·확장 등록, 이력 수정·삭제, 설정·조정, 온보딩·복구 경로를 결정론적 임시 사용자 데이터로 실행했다. 전체 33/33 통과.
- 공통 셸 기하에서 폭 380px, 문서 높이와 뷰포트 높이 일치, 긴 목록의 내부 스크롤을 검증했다. 긴 요약에서 이력 탭으로 전환할 때 외부 팝오버 높이가 달라지는 동적 높이도 확인했다. 요약·빠른 등록·이력 인라인 수정의 라이트·다크 캡처를 `YEONCHA_E2E_ARTIFACT_DIR`로 남기고, 다크 등록·수정 상태에서는 키보드 포커스도 확인했다.
- 컴프 대조에서 이력 날짜 열의 줄바꿈을 확인해 `.hist-row` 날짜 열을 84px로 넓히고 날짜를 한 줄로 유지했다. 두 날짜의 `Range.getClientRects()` 줄 수를 `[1, 1]`로 고정 검증한다.
- 승인된 `apps/desktop/.impeccable/mocks/decision/model-pick.png`와 `/tmp/yeonchamyeotgae-issue13-final/`의 `summary-first-view.png`, `summary-first-view-dark.png`, `quick-entry.png`, `quick-entry-dark.png`, `history-edit.png`, `history-edit-dark.png`를 시각적으로 대조했다. 정보 위계·정렬·주요 행동 위치는 디자인 계약에 맞았고, 컴프의 종이 질감·대형 영웅 장식은 계약상 재현하지 않았다. 발견한 날짜 줄바꿈만 수정 사항으로 남았다.
- 제품 흐름은 `mkdtemp`로 만든 격리 사용자 데이터 디렉터리와 결정론적 seed를 사용하고 종료 후 정리한다. 실제 사용자 저장 파일은 사용하지 않았다.
- 최종 검증은 `pnpm exec turbo run lint typecheck test --force --concurrency=1` 6/6 성공(`core` 123개·`desktop` 18개 단위 테스트), `pnpm test:product:foreground` 33/33 통과, `git diff --check` 통과로 확인했다.
- 사용자 환경의 메뉴 막대 트레이 숫자와 실제 클릭을 직접 관찰하는 도구 경로는 커스텀 Electron 앱을 노출하지 않아 완료하지 못했다. 따라서 첫 번째 항목은 미검증으로 남기며, macOS 결과를 Windows 수용 증거로 간주하지 않는다.
