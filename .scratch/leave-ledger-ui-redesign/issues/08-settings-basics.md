# 08: 원장형 입사일·기준방식 설정

**What to build:** 사용자가 입사일과 기준방식을 원장형 설정 화면에서 이해하고 변경하며, 기존
휴가 기록에 영향을 주는 변경은 결과를 확인한 뒤 선택할 수 있는 설정 흐름.

**Blocked by:** 02/잔액 원장 디자인 계약과 팝오버 셸.

**Status:** ready-for-agent

- [ ] 현재 입사일과 기준방식이 고정된 라벨·값 구조로 읽힌다.
- [ ] 입사일 기준과 회계연도 기준을 선택하고 저장할 수 있다.
- [ ] 값이 바뀌지 않았거나 유효하지 않으면 저장 행동이 비활성이고 이유를 이해할 수 있다.
- [ ] 입사일 변경으로 이전 휴가 기록과 조정이 영향을 받으면 보존하거나 삭제할 대상을 저장 전에 설명한다.
- [ ] 삭제를 선택하면 기존 백업 계약이 유지되고, 보존을 선택하면 대상 기록이 남는다.
- [ ] 저장 중 중복 조작이 막히고 실패 시 입력값과 설명이 유지된다.
- [ ] 설정 저장 후 잔여와 관련 화면이 즉시 다시 계산된다.
- [ ] 키보드와 보조 기술이 라벨, 입력 오류, 선택과 확인 상태를 이해할 수 있다.
- [ ] Electron 제품 흐름이 기준방식 변경과 기록 보존·삭제 확인을 검증한다.
