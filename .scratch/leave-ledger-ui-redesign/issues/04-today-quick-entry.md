# 04: 오늘 휴가 2회 조작 등록

**What to build:** 요약의 휴가 등록을 열면 오늘과 종일이 선택된 한 화면이 나타나고, 사용자가
휴가 등록과 등록의 두 번 조작으로 오늘 종일 휴가 기록을 저장하는 빠른 흐름.

**Blocked by:** 03/잔여 원장 요약 첫 화면.

**Status:** ready-for-agent

- [x] 휴가 등록을 열면 오늘 날짜와 종일이 기본값으로 명확히 표시된다.
- [x] 기본값을 바꾸지 않으면 등록 버튼 한 번으로 오늘 종일 휴가 기록이 저장된다.
- [x] 오늘에 이미 휴가 기록이 있으면 중복 저장이 막히고 다른 날짜를 고를 수 있는 설명이 보인다.
- [x] 저장 중에는 중복 조작이 막히고 완료 또는 실패 상태가 같은 등록면에 표시된다.
- [x] 저장 실패 시 사용자가 보고 있던 값과 입력 맥락이 유지된다.
- [x] 저장 성공 후 잔여, 요약, 휴가 이력과 트레이 표시가 함께 갱신되고 등록면이 닫힌다.
- [x] 다른 날짜와 기간을 기록하는 기존 기능은 이 티켓을 적용한 뒤에도 사용할 수 있다.
- [x] 키보드만으로 등록면을 열고 기본값을 확인하고 저장하거나 닫을 수 있다.
- [x] Electron 제품 흐름이 두 번의 조작과 저장 전후 잔여 변화를 검증한다.
