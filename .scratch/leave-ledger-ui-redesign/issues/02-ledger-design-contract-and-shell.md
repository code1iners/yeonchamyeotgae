# 02: 잔액 원장 디자인 계약과 팝오버 셸

**What to build:** 승인된 잔액 원장 컴프를 구현 기준으로 삼는 디자인 계약과 팝오버 공통 셸.
새 원장형 토큰을 기존 화면 옆에 확장하고 제품명, 탭, 버튼, 입력, 기준선과 포커스가 모든
후속 화면에서 재사용될 수 있게 한다.

**Blocked by:** 01/격리된 Electron 제품 흐름 검증선.

**Status:** ready-for-agent

- [x] 디자인 권위 문서가 잔액 원장의 정보 위계, 색 역할, 글자, 숫자 정렬, 간격과 금지 요소를 설명한다.
- [x] 승인된 컴프는 다시 생성하지 않고 구성과 주요 행동 위치의 기준으로 보존한다.
- [x] 팝오버 공통 셸이 따뜻한 중립 표면, 짙은 잉크색과 절제된 원장 녹색의 역할 토큰을 사용한다.
- [x] 요약·이력·설정 탭과 공통 버튼·입력이 라이트·다크 테마에서 같은 의미 구조를 유지한다.
- [x] 팝오버는 380px 고정 폭과 내용 기반 높이를 유지하고 화면 작업 영역을 넘지 않는다.
- [x] 탭 선택과 키보드 포커스가 의미에 맞는 역할과 시각 표시를 가진다.
- [x] 아직 이관하지 않은 화면은 기존 기능과 모양을 유지한 채 새 셸 안에서 동작한다.
- [x] Electron 제품 흐름이 탭 이동과 공통 셸의 기본 접근성을 확인한다.
