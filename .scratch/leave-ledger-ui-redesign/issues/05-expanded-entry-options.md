# 05: 날짜·기간·단위 확장 등록

**What to build:** 빠른 오늘 기록을 유지하면서 다른 날짜, 기간, 종일·반차·반반차, 메모와
주말 제외를 같은 등록면에서 조정하고 저장하는 완전한 휴가 등록 흐름.

**Blocked by:** 04/오늘 휴가 2회 조작 등록.

**Status:** ready-for-agent

- [ ] 날짜 선택이 기본값과 같은 등록면에서 열리고 다른 페이지나 중첩 모달을 만들지 않는다.
- [ ] 시작일과 종료일을 골라 기간을 만들고 시작·종료를 반대로 골라도 올바른 범위로 정규화된다.
- [ ] 기간에서는 주말 제외가 기본으로 켜지고 실제 생성될 휴가 기록 수가 저장 전에 보인다.
- [ ] 기존 휴가 기록이 있는 날짜는 중복 생성되지 않으며 생성할 날짜가 없으면 등록이 비활성이다.
- [ ] 종일·반차·반반차가 각각 1일·0.5일·0.25일로 저장된다.
- [ ] 메모는 선택 사항이며 앞뒤 공백을 제거해 각 휴가 기록에 저장한다.
- [ ] 기간은 저장 형식을 바꾸지 않고 날짜별 휴가 기록 여러 건으로 펼쳐진다.
- [ ] 등록 취소와 날짜·기간 변경이 입력 맥락을 잃지 않고 동작한다.
- [ ] Electron 제품 흐름이 다른 날짜, 기간, 단위, 메모, 주말 제외와 중복 날짜를 검증한다.
- [ ] 기존 기간 날짜 전개 단위 테스트가 회귀 없이 통과한다.
