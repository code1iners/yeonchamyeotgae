# 01: 격리된 Electron 제품 흐름 검증선

**What to build:** 실제 Electron 앱을 결정론적 시드 데이터와 격리된 사용자 데이터로 실행해
팝오버의 외부 동작을 검증하는 Playwright 제품 흐름. 이후 모든 UI 재설계 티켓은 이 한 경계에
시나리오를 추가한다.

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] 제품 흐름이 빌드된 Electron 앱을 실행하고 팝오버 창을 열고 닫을 수 있다.
- [ ] 각 실행은 임시 사용자 데이터만 사용하며 개발자나 사용자의 실제 저장 파일을 읽거나 바꾸지 않는다.
- [ ] 정상 데이터, 입사일이 없는 데이터와 읽기 실패 상태를 결정론적으로 준비할 수 있다.
- [ ] 정상 데이터 스모크 시나리오가 잔여와 요약·이력·설정 탭을 사용자에게 보이는 문구와 역할로 확인한다.
- [ ] 테스트는 CSS 클래스, React 상태와 컴포넌트 구조를 관찰하지 않는다.
- [ ] 제품 흐름 실패 시 앱 프로세스와 임시 데이터가 정리된다.
- [ ] 기존 정적 검사와 자동 테스트가 계속 통과한다.
