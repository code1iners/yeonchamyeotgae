# 03: 잔여 원장 요약 첫 화면

**What to build:** 팝오버를 열자마자 잔여와 휴가 등록 행동을 보고, 발생·사용·예정·초과·잔여와
살아 있는 발생분을 같은 원장 열에서 검산할 수 있는 요약 화면.

**Blocked by:** 02/잔액 원장 디자인 계약과 팝오버 셸.

**Status:** ready-for-agent

- [ ] 잔여와 휴가 등록 행동이 최초 뷰포트 안에 있으며 스크롤이나 탭 이동이 필요 없다.
- [ ] 발생·사용·예정·조건부 초과·잔여가 고정된 수량 열과 짧은 설명으로 표시된다.
- [ ] 미래 발생분에서 나가는 예정의 근거 문구가 기존 계산 결과를 그대로 설명한다.
- [ ] 살아 있는 발생분이 소멸 임박 순으로 출처, 남은 양, 총량과 소멸일을 표시한다.
- [ ] 소멸 임박과 초과는 색 외의 문구나 기호로도 구분된다.
- [ ] 숫자는 소수 값을 그대로 표시하고 값이 바뀌어도 열이 흔들리지 않는다.
- [ ] 초과에서 조정으로 가는 기존 행동이 현재 맥락을 보존한다.
- [ ] Electron 제품 흐름이 잔여와 휴가 등록의 실제 위치, 요약 값과 스크롤 경계를 확인한다.
- [ ] 승인된 컴프와 비교할 결정론적 첫 화면 스크린샷을 남긴다.
