# 12: 기존 시각 계약 제거와 공통 접근성 수축

**What to build:** 모든 화면 이관 뒤 남은 기존 시각 계약을 제거하고, 잔액 원장의 숫자·날짜
정렬, 상태 표현, 포커스와 스크롤 규칙이 팝오버 전체에서 하나로 동작하게 하는 수축 단계.

**Blocked by:** 05/날짜·기간·단위 확장 등록, 07/원장형 휴가 이력 달력과 날짜 조작,
09/원장형 조정 관리, 11/첫 실행과 읽기 실패 복구.

**Status:** ready-for-agent

- [ ] 사용 중인 모든 화면이 디자인 권위 문서의 역할 토큰과 원장형 공통 요소만 사용한다.
- [ ] 더 이상 호출되지 않는 기존 시각 토큰, 선택자와 임시 호환 계층이 제거된다.
- [ ] 라이트·다크 테마가 같은 정보 위계와 상태 의미를 유지한다.
- [ ] 잔여, 수량, 날짜와 행 행동이 상태 변화 후에도 정렬을 유지한다.
- [ ] 상태는 색상만으로 전달되지 않고 문구, 기호 또는 접근 가능한 이름을 함께 가진다.
- [ ] 탭 순서, 포커스 복귀, 펼침 상태, 오류와 저장 중 상태가 팝오버 전체에서 일관된다.
- [ ] 화면 작업 영역을 넘는 경우 필요한 목록만 스크롤되고 핵심 머리와 행동은 유지된다.
- [ ] 키보드만으로 요약, 등록, 이력, 설정, 온보딩과 복구의 주요 흐름을 완료한다.
- [ ] 정적 검사, 단위 테스트와 전체 Electron 제품 흐름이 마지막 변경 이후 통과한다.
