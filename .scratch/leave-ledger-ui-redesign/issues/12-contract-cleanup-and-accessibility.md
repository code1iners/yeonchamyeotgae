## Answer

- `DataSection`의 항상 참인 `hasSavedFile` 호환 분기와 등록면의 고립된 `sheet` 선택자를 제거하고, 사용 중인 원장 역할 토큰과 공통 요소만 남겼다. `apps/desktop/DESIGN.md`에는 조정 원장의 고정 열, 240px 내부 스크롤과 포커스 계약을 추가했다.
- 조정 목록은 목록만 스크롤하도록 고정하고 설정 머리와 데이터 행동을 유지한다. 조정 추가·수정은 일수 입력에서 시작하며, 저장·취소 뒤 원래 행동으로 포커스를 돌리고 삭제로 행이 사라지면 조정 추가 버튼으로 이어진다. 이력 수정도 날짜 입력 시작과 같은 행 복귀를 보장하고, 달력 기록 삭제 뒤 선택 상세로 포커스를 옮긴다.
- 휴가 등록면은 `dialog` 내부 Tab 포커스를 순환시키고, Escape·취소·완료 뒤 요약의 `휴가 등록` 버튼으로 포커스를 복귀시킨다. 진행 상태는 `aria-busy`와 기존 live status로 전달하며, 예정·사용·소멸·D-day 상태는 문구·기호·접근 가능한 이름을 함께 유지한다.
- 검증은 `pnpm exec turbo run lint typecheck test --force --concurrency=1` 6/6 작업 성공(코어 123개·데스크톱 18개 단위 테스트), `pnpm test:product` 실제 Electron 비활성 제품 흐름 33/33 통과, `pnpm test:product:foreground` macOS 포그라운드 제품 흐름 33/33 통과로 마쳤다. 제품 흐름은 격리된 임시 사용자 데이터와 결정론적 fixture를 사용했으며, Windows 실제 트레이·팝오버·포커스 검증은 포함하지 않는다.
