# 20. 온보딩 — 탭 셸과 입사일 입력

Type: task
Status: ready-for-agent
Blocked by: 19

## What to build

앱을 처음 실행하면 **입사일을 넣는 화면이 바로 열리고**, 입사일과 기준방식을 저장하면 파일이
생기고 트레이 숫자가 그 자리에서 바뀐다. 팝오버의 탭 3개(요약 / 이력 / 설정) 골격이 이 티켓에서 선다.

`ui-design` Skill을 적용한다. 실제 메뉴바 앱(runcat, Itsycal, Stats)의 기성 패턴을 우선하고,
시각 언어는 **시스템 네이티브, 장식 없음, 강조색은 시스템 블루 하나**다([스펙 5절](../spec.md)).

- **입사일이 없으면 설정 탭만 활성이고 요약·이력은 비활성**이며 **조정 섹션도 감춘다** — 입사일도
  없는데 조정을 넣을 이유가 없다.
- 온보딩이 말해야 하는 것은 `입사일을 넣으면 연차를 계산합니다` **한 줄**이다.
- **온보딩 화면에 글리프를 넣지 않는다**(6절) — 방금 그 글리프를 눌러 들어왔다.
- 트레이의 대시를 누르면 **설정 탭이 열린다**(4.4절).
- **별도 창을 만들지 않는다.** 전부 팝오버 안이다.

요약·이력 탭의 내용은 뒤 티켓(24 / 26)이다. 이 티켓은 탭 전환과 활성/비활성 규칙까지다.

## Acceptance criteria

- [ ] 첫 실행에서 팝오버가 설정 탭으로 열리고 입사일 입력이 바로 보인다
- [ ] 입사일이 없는 동안 요약·이력 탭이 비활성이고 조정 섹션이 보이지 않는다
- [ ] 입사일과 기준방식(입사일 기준 / 회계연도 기준)을 저장하면 `data.json`이 처음 생기고 트레이가 대시에서 숫자로 바뀐다
- [ ] 세 탭이 전환되고 팝오버 높이가 탭 내용에 맞춰 달라진다(폭은 380px 고정)
- [ ] 트레이 대시를 누르면 설정 탭이 열린다
- [ ] 입사일을 바꾸면 계속근로연수가 리셋된 값으로 트레이가 갱신된다(이전 기록 삭제 여부를 묻는 것은 23번)
- [ ] 별도 창이 없고, 렌더러가 도메인 규칙을 직접 계산하지 않는다(전부 코어의 결과를 받아 그린다)
