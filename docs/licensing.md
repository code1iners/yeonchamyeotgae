# 라이선스 안내

## 현재 적용된 라이선스

이 프로젝트의 저작권자 소유 코드와 문서는 [MIT License](../LICENSE)를 따릅니다. MIT는
[Open Source Initiative의 공식 라이선스 전문](https://opensource.org/license/mit)처럼 다음
행위를 무료로 허용합니다.

- 소프트웨어를 사용하고 복제하기
- 소스 또는 실행 파일을 수정·병합해 2차 저작물 만들기
- 공개하고 배포하기
- 다른 조건으로 재허가하거나 판매하기
- 상업적으로 이용하기

재배포할 때는 원본의 저작권 고지와 MIT 허가 고지를 모든 복사본 또는 상당 부분에 포함해야
합니다. 그 밖의 보증은 제공되지 않으며, 소프트웨어는 “있는 그대로” 제공됩니다.

MIT는 수정·재배포를 제한하는 라이선스가 아닙니다. 따라서 나중에 가공·재배포를 제한하려면
MIT 문구에 제한을 덧붙이는 대신 별도의 라이선스 정책을 새로 정해야 합니다.

## 적용 범위

이 저장소의 MIT 라이선스는 별도 고지가 없는 프로젝트 소유 코드와 문서에 적용됩니다. Electron,
의존성, 아이콘 등 제3자 저작물은 각자의 라이선스가 우선하며, 배포본을 만들 때 해당 조건도
확인해야 합니다.

`LICENSE`의 `code1iners` 표기는 현재 GitHub 저장소 소유자에 맞춘 것입니다. 법적 저작권자 이름이나
법인명이 다르다면 실제 권리자 표기로 교체해야 합니다.
